# 青禾果园守护交互 Demo

这是用于确认移动端界面和操作流程的本地前端原型。所有识别结果、告警和设备回执均为模拟数据；监控画面为项目内置 SVG 场景插画，不连接模型、真实后端或硬件。

## 启动

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4178 。桌面展示手机界面与流程说明，窄屏展示移动端布局。此版本是浏览器 Demo，不是 Android 安装包。

## 体验流程

1. 从监控页进入待处理告警，查看识别详情。
2. 点击“确认并去驱离”，选择时长，确认执行。
3. 查看倒计时与模拟回执；在记录页查询关联告警和操作时间线。
4. 在右上角演示设置中切换离线或超时场景，或新增告警、重置数据。
5. 执行中可停止；停止或超时后，关联告警恢复待处理。

模拟数据保存在当前浏览器 localStorage 中。刷新会把未完成的模拟任务标记为结果未知，不会自动继续执行。所有成功提示只表示模拟指令完成，不表示真实驱鸟效果。

## 验证

```sh
npm test
npm run check
```

测试覆盖告警与执行关联、重复下发、离线、超时、停止、告警合并和刷新恢复。

## 文件

- `demo/`：界面、样式、内置图像及模拟状态逻辑。
- `scripts/serve.mjs`：仅用于静态文件预览的本地服务器。
- `tests/demo.test.mjs`：模拟业务逻辑测试。
- `docs/产品设计文档-MVP.md`：后续真实 MVP 的产品范围。
