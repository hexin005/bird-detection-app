# H5 视频检测与分类改进

本轮优先完善 H5。Android AppID、证书、APK 打包和真机验收暂缓。

## 使用流程

1. 首页点击“选择视频”，上传电脑上的 MP4、MOV、AVI、MKV 或 WebM，单文件不超过 500 MB。
2. 点击“开始检测”。后端分析录像并连续编码，首段视频生成后即可播放；如果分析速度跟不上播放，会缓冲等待。
3. 分析完成后自动保存检测档案与带框 MP4，支持回看、拖动进度条和下载；档案内可切换原视频对照，也能下载原片（原片能否直接播放取决于浏览器的格式支持）。
4. 告警页保留“全部待处理”，另有“按鸟类分类”；每个目录显示告警条数和待处理条数。
5. 记录页默认显示视频档案，也可以按鸟类查找。一个视频包含多种鸟时，多个分类都引用同一份视频。
6. 档案中显示鸟类出现的时间段，点击可跳转；告警详情也提供跳转对应视频位置的入口。

## 实现方式

- 播放与识别分开：保留原视频帧率，模型按采样帧检测；检测框在相邻采样之间短暂保持，不代表每一帧都重新推理。
- FFmpeg 将完整画面编码为 H.264 / HLS 片段；H5 使用 hls.js 或浏览器原生 HLS 播放，完成后合成为 MP4，并尝试保留原视频音轨。
- 片段全部保留，支持回看已处理部分；主动停止后，已处理部分归档并明确标记为部分结果。
- 告警合并按录像时间计算，避免处理速度改变告警合并结果；鸟类出现时间段和单帧峰值数量单独索引，不累计为独立鸟只数。
- 原始上传文件保存在 `.runtime/videos/`；检测片段、结果视频保存在 `.runtime/jobs/<任务ID>/`；索引保存在 SQLite 中。
- 视频文件使用短时媒体授权，支持浏览器 Range 请求与下载；原 API 会话令牌不写入视频地址。
- 旧版本告警和操作记录继续保留；旧任务未保存结果视频，无法补出历史回放。新建检测任务后即可使用完整档案功能。

## 运行要求

继续使用原启动方式：`npm run build:h5`、`npm run dev:mvp`。新增依赖通过 `npm --prefix mobile ci` 安装。

服务器需要 FFmpeg，默认从 PATH 查找，也可用 `BIRD_FFMPEG` 指定完整可执行文件路径。本机已验证已安装的 FFmpeg 可用。

视频默认保存在运行后端的电脑磁盘。浏览器通过下载入口另存到自己的设备。本轮没有增加自动删除功能，避免无意删除检测档案。

## 验证范围

- 原后端与模拟驱离回归测试。
- 上传授权、无效文件拒绝和清理、中文文件名、视频索引、鸟类分组、录像时间合并规则。
- 多鸟类引用同一视频、无鸟任务保留、历史待处理计数、媒体授权、Range 播放、私有编码日志不可访问。
- 真实 YOLO + FFmpeg 集成：保留原视频帧率/帧数、MP4 解码、HLS 产出、告警与视频关联、重启后档案和分类仍可查询。
- H5 实际上传 12 秒样例，验证结果视频播放、鸟类目录、档案回看及出现时间跳转。

流畅播放不等于推理零延迟。速度取决于机器、输入分辨率和模型；首版接受必要缓冲，保留真实模型的误检、漏检情况供人工判断。
