八哥 · Crested Myna✕
本园最近抓拍 · 11-11 07:29 · 置信 93%
对果园的影响

高危害。成群活动，啄开果皮取食果肉，被啄破的果实极易二次腐坏；果实成熟期损失最大，是本园重点驱防对象。

识别特征

通体黑亮带金属光泽，飞行时翼上可见明显白斑，集群停落时鸣叫喧闹。

活动时段

昼间活动，清晨与傍晚最活跃，常成群往返果园与林地。

本园应对

模型持续盯防，检出即告警；声波 / 双模驱离对集群个体有效，驱散后短期不易回巢。
