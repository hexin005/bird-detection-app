# 青禾 · 果园守护 — UI 重设计需求书

> 用途：交给 AI 设计模型（Claude / ChatGPT / v0 / Lovable / 即梦 等）做界面重设计。
> 请把本文件 + `screens/` 目录下的 6 张截图一起提供给对方。

---

## 一、一句话说明这个项目

**面向果园管理人员的鸟类监测与远程驱离 App**：摄像头识别鸟类 → 触发告警 → 人工核对后远程驱离 → 归档记录。当前是软件 MVP，驱鸟设备为模拟执行器。

**技术栈**：uni-app + Vue 3 + TypeScript + Pinia，产物是 H5 页面（未来可能打包 Android）。**移动端优先**，桌面端只是居中展示手机外壳的展示态。

## 三、产品气质定位（这是重设计的关键）

**不要做成**：
- ❌ 通用后台管理 / SaaS 仪表盘
- ❌ 科技蓝、暗黑赛博、渐变霓虹
- ❌ 堆砌图表和数字的"数据大屏"

**要做成**：
- ✅ **农业 + 自然的克制感**，像一本安静的田园笔记
- ✅ **可信赖的工具感**，果农在果园里单手能操作
- ✅ **有温度的克制**，用留白和材质表达质感，而不是靠装饰
- ✅ 参考气质：日式杂货、MUJI、Aesop、无印良品式的"少即是多"

**核心情绪词**：安静、可靠、克制、有生命力、被守护

### 4.1 监控页

```
[顶部] 果园名称「青禾示范果园」+ MVP 标签 + 监控点「东区 · 01 号监控点」+ 设置入口
[连接状态条] 「实时连接」/「重连中 · 查询补偿」/「连接中断」
[标题区] 主标题 + 副标题 + 任务状态徽标（未开始/加载模型/正在监测/检测完成/已停止/检测异常）
[视频区] 
  - 检测画面（带 YOLO 检测框、类别名、置信度）
  - 左上角「录像演示 · YOLOv8」标签
  - 右下角「视频 12.5s / 304s · 第 375 帧」
  - 无画面时占位：「导入视频，开始一次鸟类巡护」
[视频源栏] 当前视频名 + 时长 + 「选择视频」按钮
[上传进度] 「正在上传 45%」+ 进度条
[操作栏] 状态说明文字 + 「开始检测」/「停止分析」主按钮
[检测进度条] 分析中显示百分比
[归档提示]「本次结果已归档，可在记录中回看。」+「下载结果视频 ↓」
[指标区] 待处理告警 N 条 / 检测事件 N 条 / 模拟执行完成 N 次
[待处理告警卡] 鸟类图表符 + 「发现 2 只珠颈斑鸠」+ 监控点 + 待处理徽标 + 时间 + 置信度 +「查看并处理 ›」
[设备条] 声学驱鸟器 01 + 「模拟设备 · 人工确认后执行」+ 在线/离线状态
[底部导航] 监控 / 告警(带未读数) / 控制 / 记录
```

### 4.5 登录页 & 设置

```
[登录] 欢迎回来 / 开启今天的巡护 / 连接你的果园监测服务
      服务地址输入 + 账号输入 + 密码输入 + 「登录并进入果园」
      提示：「账号由本地服务创建。手机访问时，填写电脑的局域网地址……」

          操作记录（时间线：人工确认 → 开始执行 → 状态 + 消息）
```

## 五、可用的数据字段（真实 API，设计时按此排布）

```ts
  at, started_at, ended_at, message
```

## 六、重设计要求

### 6.1 必须做到

1. **移动端 390×844 为基准**，桌面端 1440 宽三栏展示（品牌叙事 / 手机 / 提示）
2. **单手可操作**：主操作按钮在拇指热区（屏幕下 1/3）
3. **触控目标 ≥ 44×44px**
4. **状态必须可视**：8 种监控状态、6 种指令状态、4 种告警状态，都要有清晰视觉区分
5. **保留"录像演示""模拟设备"的明确标注**（这是答辩合规要求，不能让人误以为是真实硬件）
6. 深色视频画面与浅色界面要和谐共存

### 6.2 请给出

1. **设计方向说明**：配色逻辑、材质/肌理、排版节奏的依据
2. **完整 design token**：颜色（含语义色）、字号阶梯、间距体系、圆角、阴影、动效
3. **5 个核心页面的高保真稿**：监控 / 告警 / 控制 / 记录 / 登录
4. **关键组件状态**：按钮 4 态、输入框 3 态、徽标 14 态、卡片 hover/active
5. **弹窗设计**：设置 / 告警详情 / 确认执行 / 操作记录
6. **暗色模式**（可选但加分）

### 6.3 交付格式

优先给 **可直接落地的 CSS 变量 + 组件样式**（因为我们要接回 uni-app 的 Vue 组件），或至少给 **Figma 式的结构化标注**（每个元素的位置、尺寸、颜色、字号、圆角）。

## 七、当前约束（别设计做不到的东西）

| 约束 | 说明 |
| --- | --- |
| 渲染环境 | uni-app H5，`<view>/<text>/<button>/<input>/<image>/<progress>/<scroll-view>` 这些原生标签，**不是普通 div** |
| 样式能力 | 支持 CSS 变量、flex、grid、`backdrop-filter`、`@keyframes`；**不支持** 复杂 JS 动画库的重量级方案 |
| 图标 | 当前用 Unicode 字符（▣ ♧ ◉ ▤ ▷ ◎ ☷），可以换 SVG 或图标字体，但请说明方案 |
| 字体 | 系统中文字体栈，不引入外部字体文件（体积 + 加载） |
| 图片 | 检测画面是 JPEG 帧，视频是 HLS/MP4，抓拍是 JPEG |
| 性能 | 低端安卓机要能跑，避免大面积 blur / 多层阴影叠加 |
