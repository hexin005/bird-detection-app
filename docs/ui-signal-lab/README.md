# 鸟情信号站 · 布局实验室

独立 HTML 交互方案，覆盖告警中心、远程控制、检测记录；不接业务 API，不改变原应用。

## 四个方向

| 方案 | 主要结构 | 适合的使用方式 |
| --- | --- | --- |
| 公共告示 | 证据与待办并列、三步执行、日期归档 | 日常使用，推荐先看 |
| 值班案卷 | 案卷侧栏、纸本条目、执行单 | 强调核对和留痕 |
| 调度台 | 可选中队列与联动证据、暗色设备席、紧凑日志 | 长时间值班和快速处理 |
| 现场手册 | 单条鸟情优先、编号步骤、图片记录 | 手机与现场操作 |

## 本轮改善的原布局问题

- 去掉占满背景的棋盘纹和无差别粗边框。
- 将鸟类筛选和待办状态常驻显示。
- 控制页按方式、时长、确认组织，缩小装饰设备图。
- 记录分类平级化：视频档案、鸟类目录、操作日志。
- 按日期组织档案；避免首屏加载几十张同质卡片。

## 预览

在项目根目录运行：

```powershell
python -m http.server 4189 --bind 127.0.0.1 --directory docs/ui-signal-lab
```

打开 http://127.0.0.1:4189/ 。顶部切换四个方案，下方切换三个页面。
桌面可点击“手机尺寸预览”，也支持真实窄视口。

可操作：鸟类筛选、核对详情、忽略告警、关联驱离、方式与时长选择、离线状态、确认模拟执行、停止、执行回执、视频与鸟类分类、日期过滤、日志、视频播放与时间点跳转、下载示例录像、重置。

所有编号、日期、数量为示例数据；照片与斑鸠视频来自项目已有演示素材。档案中的播放器统一使用斑鸠演示录像，并在弹窗中标注。WebM 为兼容预览浏览器而转换的副本。
