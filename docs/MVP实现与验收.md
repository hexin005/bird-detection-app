## 已实现范围

| 模块 | 当前实现 |
| --- | --- |
| 移动界面 | uni-app + Vue 3 + TypeScript + Pinia；沿用青禾 Demo 的配色和布局；监控、告警、控制、记录、登录和设置 |

| 画面展示 | 后端将检测框画在对应视频帧上，携带任务、帧号和录像时间；客户端加载该帧后显示对应信息，过期画面标记为最后画面 |
| 告警 | 按置信度、连续检出及合并间隔产生告警；保存首次抓拍与该画面的数量，连续检出只增加命中次数 |
| 模拟驱离 | 人工确认、3/5/8 秒执行、停止；待执行/执行中/完成/失败/取消/未知状态；唯一请求号与事务防止重复执行 |
| 异常 | 离线拒绝下发，超时不标成功，重连不自动重放，服务中断将未完成指令恢复为结果未知、关联告警恢复待处理 |
| 持久化与通信 | SQLite 保存告警、指令和事件；WebSocket 推送与 HTTP 补拉；记录支持向前分页，抓拍采用短时媒体授权 |

## 复用情况

- 使用现有网页项目同一份模型权重，不重新训练、不改写原权重。
- 复用网页项目中 YOLO 调用、框数据提取及密码校验的实现思路，并在新后端中按 MVP 拆分与补全。
- 将原 Demo 的流程和样式迁移到 Vue；没有直接嵌入原 HTML 页面冒充 uni-app。
- 新建独立 SQLite 数据库和模拟执行逻辑，避免把演示记录混入原网页数据库。
- 本机利用已安装的 Python 推理环境启动，新环境支持独立安装。

## Android 打包与真机验收

`npm run build:app` 产物位于 `mobile/dist/build/app`，属于 uni-app App 资源，**不是可安装 APK**。

完成安装包需要：

1. 为本项目配置 DCloud AppID，填写 `mobile/src/manifest.json`；不要复用无关项目的身份。
2. 在与编译器匹配的 HBuilderX 中导入移动端工程，配置 Android 包名和签名，以本地或云打包方式生成 APK。云打包前需确认使用该账户及上传源码的授权。
3. 在 Android 真机上填写局域网服务地址，分别验证登录、画面刷新、WebSocket、告警关联、执行与停止、切后台后恢复等场景。

本次环境未检测到已连接的 Android 设备，尚未完成真机安装及验收；不以 H5 通过替代 Android 通过。

### 与山区 App 的配置区分

- **DCloud AppID**：代表 DCloud 平台中的应用身份，本项目应新建独立 AppID，不能把山区 App 的 AppID 当成果园产品的身份。
- **Android 包名**：建议为本产品使用独立包名，例如 `com.qinghe.orchardwatch`，避免与山区 App 相互覆盖。
- **自有签名证书**：同一开发者可以用自己的同一份证书签署多个不同包名的应用；这不意味着复用 AppID 或包名。需要确认已有证书的持有权、文件、别名及密码，并按新应用配置。
- **DCloud 云证书**：自动生成的证书绑定 AppID，新 AppID 可生成自己的云证书；不能直接把另一个项目的云证书配置原样复制过来。

开发阶段建议给果园应用新建 AppID 并使用其独立云证书。当前源码和构建资源已经准备好，尚未调用云打包、上传源码或读取山区 App 的签名私钥。

参考：[DCloud AppID 说明](https://uniapp.dcloud.net.cn/dev/app/introduction.html)、[Android 云端打包证书说明](https://ask.dcloud.net.cn/article/35985)。

## 当前限制

- 录像以连续标注 JPEG 帧展示，不包含原视频音频或完整帧率播放；这是首版明确采用的展示方式。
- 单果园、单检测任务、单模拟执行器；后端使用单进程启动，暂不配置多个 Uvicorn worker。
- 无真实硬件、无系统级后台推送、无自动驱离、无微信小程序适配。
- 不自动下载模型或视频。项目迁移时需要提供权重与素材，按 README 配置路径。
- 原始录像只用来验证识别与界面流程，不作为实际驱鸟效果证据。
