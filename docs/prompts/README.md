## 方法与真实性说明

1. **来源真实**：所有 Prompt 原文摘录自 ZCode 本机会话记录，未做改写；仅对超长段落做
   `⋯` 省略标记（完整原文可从会话记录随时再次导出，亦可靠录屏复现）。
2. **可交叉验证**：每条链标注了对应的 Git 提交哈希，提交 message 中的功能点与
   Prompt 链中的对话节点一一对应；`git log` 的细粒度历史（53+ commits，禁止一次性提交）
   即本 Prompt 链的代码侧证据。
3. **脱敏声明**：原文中出现的账号密码等敏感凭据一律以 `********` 代替，其余内容保持原样。
4. **修 Bug 过程的呈现方式**：每条链的「Bug 修复」小节按
   现象 → 根因定位 → 修复引导 → 回归验证 四段还原，均为真实发生的过程记录。
